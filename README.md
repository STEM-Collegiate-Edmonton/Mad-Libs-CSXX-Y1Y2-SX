# Mad Libs Story Generator

Create a Python program in `main.py` that asks the user for information and uses their answers to create a short Mad Libs-style story. The main focus is practicing `input()`, `print()`, f-strings, and newline characters to create clear formatted output.

## Requirements

* [ ] Ask the user for at least **5 different pieces of information** using `input()` and store each response in a variable.
* [ ] Use clear prompts that tell the user what kind of word or information to enter.
* [ ] Create an original Mad Libs-style story that uses **every value entered by the user**.
* [ ] Use at least one **f-string** to insert variables into the story.
* [ ] Use `\n` to organize the story across multiple lines.
* [ ] Use `print()` to display the completed story after all user input has been collected.
* [ ] Use clear and descriptive `snake_case` variable names.

For example, your program might ask for:

```text
Enter a name: Jordan
Enter a place: Mars
Enter an adjective: enormous
Enter an animal: penguin
Enter a food: pizza
```

A possible output could be:

```text
Jordan travelled all the way to Mars.
When they arrived, they discovered an enormous penguin.

The penguin looked at Jordan and said,
"I have been waiting for my pizza!"
```

Your story should be your own and should change based on what the user enters.
